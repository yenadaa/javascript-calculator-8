# 문자열 덧셈 계산기

### 개요
- 우아한 테크코스 1주차 프리코스 과제 제출본입니다.
- 사용자에게 문자열을 입력받아 문자열 중 숫자만 더하는 계산기입니다.
- 구분자와 양수로 구성된 문자열만 취급합니다.

## 📌 목차
1. 기능 목록
2. 예외 상황 테스트
3. 디자인
---

## 🚀 기능 목록
### 입력 기능
- [ ] 사용자에게 '덧셈할 문자열을 입력해 주세요.'라는 문구로 입력을 받습니다.

### 문자열 파싱 및 덧셈 기능
- [ ] 쉼표(,)와 콜론(:)을 기본 구분자로 설정합니다.
- [ ] 문자열 앞 부분에 '//'와 '\n' 사이에 있는 커스텀 구분자가 있는지 확인합니다.
- [ ] 문자열에서 구분자를 기준으로 분리하여 숫자를 추출합니다.
- [ ] 문자열에서 커스텀 구분자를 기준으로 분리하여 숫자를 추출합니다.
- [ ] 추출한 숫자들을 다 더하여 변수에 저장합니다.
- [ ] 빈 문자열 입력 시 0을 반환합니다. ("" => 0)
- [ ] 구분자 없이 숫자만 있을 경우 해당 숫자를 그대로 반환합니다. ("123" => 123)

### 출력 기능
- [ ] 변수에 저장한 값을 '결과 : {값}' 형식으로 화면에 출력합니다.
---

## ⚠️ 예외 상황 테스트

사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시킨 후 애플리케이션은 종료되어야 한다.

### 문자열 입력
- [ ] 문자열에 숫자가 존재하지 않을 경우
- [ ] 문자열에 음수가 존재할 경우
- [ ] 문자열에 숫자와 구분자를 제외한 문자가 존재할 경우
- [ ] 문자엘에 구분자만 존재할 경우
